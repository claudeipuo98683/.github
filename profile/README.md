<p>与其争论哪家纯净，不如做一次小规模对照：挑三条候选线路，跑完全相同的动作两个星期，把结果摆在一张表上。这种方法不依赖服务商的宣传口径，也不用懂太深的技术，只要保证变量控制住，结论就不会太离谱。下面把实验设计、三组对照和读数方法写清楚。</p>

<h2>一、实验怎么设计：三条线，一套动作</h2>
<p>实验成立的前提是「只变一个变量」。三条线之外的设备、浏览器版本、操作脚本、测试时段，全部保持一致，否则结果没法归因。</p>
<h3>样本选择：一条贵、一条中、一条便宜</h3>
<p>按价格分三档选，不要三条都买最贵的。对照组的意义在于拉开差距，同价位之间比不出东西。</p>
<h3>每天固定动作，固定时段</h3>
<p>每天同一时段做同样的三件事：登录一次、加载一个列表页、发起一次短请求。记录是否弹验证、首字节时间、是否报错。两周下来每组大概四十个样本，够看出趋势。</p>

<h2>二、第一组对照：黑名单与滥用评分</h2>
<p>这一组是入门筛选，快但粗糙。目的是先把明显有问题的排掉，不是给线路排高低。</p>
<h3>查三个库，看结论是否一致</h3>
<p>Spamhaus、AbuseIPDB、Scamalytics 各查一次。三个库都说干净，可信度较高；两个说有问题，直接出局，不用再往下测。</p>
<h3>评分要看近三十天的变化</h3>
<p>评分是快照，趋势才是信息。一条线今天六十分、三十天前二十分，说明近期有邻居在用脏，这种比一直稳定六十分的更危险，因为你不知道它会不会继续恶化。</p>

<h2>三、第二组对照：共享率与邻居行为</h2>
<p>这一组是「纯净」二字的核心。同一条地址被多少人分，比评分更能决定你用它稳不稳。</p>
<h3>怎么估算共享率</h3>
<p>正规服务商会写明独享还是共享，写不清的按共享算。技术上可以看同一出口在短时间内是否出现你之外的会话特征，比如并发连接数异常、登录地区跳变，间接判断有没有别人在用。</p>
<h3>邻居行为怎么观察</h3>
<p>同一 C 段内如果集中出现大量扫描、批量请求类流量，整段信誉都会被拖累。查一下同段其他地址的公开记录，能大致看出这个段在被人干什么。</p>

<h2>四、第三组对照：历史滥用的时间线</h2>
<p>这一组最费时间，但也最能说明问题。一条地址的过去，决定了它现在的「底色」。</p>
<h3>看分配时间与转手次数</h3>
<p>新分配的段历史短，好坏都可能；频繁转手的段往往有故事。查 whois 的分配记录和 ASN 归属变更，能看出这条线是不是被反复倒卖过。</p>
<h3>看投诉的时间分布</h3>
<p>投诉集中在半年前、近期为零，属于可接受；投诉均匀分布在过去一年，说明问题持续存在。这个区别在评分上体现不出来，要自己看原始记录。</p>

<h2>五、结果怎么读，以及怎么用它谈价</h2>
<p>三组数据放在一起，会出现几种典型组合，每种对应不同的决策。</p>
<h3>评分好但共享率高：短期能用，长期别押</h3>
<p>这类线的表现是「前两天很顺，一周后开始弹验证」。适合测试和临时任务，不适合长期承载主力账号。</p>
<h3>评分一般但独享且历史干净：值得谈</h3>
<p>评分受同段影响，独享能隔绝大部分干扰。这种线往往价格没被炒高，是性价比区间，可以拿检测记录去谈长期价。</p>
<h3>怎么用数据谈价格</h3>
<p>把两周的记录整理成一页：可用率、平均首字节、验证次数。用这页纸去谈续费折扣或换线条件，比空口说「不太稳」有效得多。市场行情上，独享静态住宅月费大致六十到两百元一条，仅供参考，谈价空间通常在一到两成。</p>

<h2>常见问答</h2>
<h3>两周的样本量够吗？</h3>
<p>答：做初筛够用，做长期结论不够。两周能排除明显不合格的线，剩下的差异要靠一个月的观察才能分清，别把两周结果当最终判决。</p>
<h3>三条线要同时测还是依次测？</h3>
<p>答：同时测。依次测会把时间因素混进来，两周后市场环境都变了，结果没有可比性。</p>
<h3>评分高的线一定更稳吗？</h3>
<p>答：不一定。评分只反映公开记录，反映不了共享程度和邻居行为。这也是为什么要做三组对照，而不是看一个数字就下单。</p>
<h3>检测会不会被服务商认为是异常行为？</h3>
<p>答：正常的查询和连通测试不会。注意别做扫描或高频请求，那既没必要，也可能违反服务条款。</p>

<p>本文所述检测方法仅限对自己采购的线路做公开信息查询与连通性验证，不得用于扫描、探测他人网络或收集他人信息。</p>
